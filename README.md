# منصة ميني جي للروبوتكس والبرمجة للأطفال 🤖🚀 (Mini G Platform)

منصة تعليمية تفاعلية تقدمية (**PWA**) مخصصة لتعليم البرمجة والروبوتكس للأطفال من عمر 7 سنوات، تدمج بين البرمجة الرسومية (**Google Blockly**)، التوأم الرقمي المتزامن ثنائي وثلاثي الأبعاد (**2D/3D Digital Twin**)، والتحكم اللاسلكي اللحظي بالهاردوير عبر البلوتوث (**Web Bluetooth API**) والاتصال السلكي (**Web Serial API**) لشرائح **ESP32**.

---

## 🌟 عائلة روبوتات ميني جي الثلاثية

1. **Mini G-F (ميدالية الورش):** ميدالية مفاتيح ذكية للأطفال، ليدات RGB، محرك اهتزاز هابتيك، وحساس لمس كهروسكوني.
2. **Mini G-M (رفيق المكتب والمذاكرة):** رأس كرتوني بمحرك عنق سيرفو، شاشة عيون تفاعلية، نغمات صوتية، مع **إكمال الجسد افتراضياً**.
3. **Mini G (الروبوت الكامل 50 سم):** قيادة عجلات، مفاصل أذرع، حوار بالذكاء الاصطناعي التوليدي مع شخصيات تاريخية وعلمية ومحاكاة الشفاه (Lip-sync).

## 🚀 التثبيت والتشغيل المحلي (Local Development)

```bash
# تثبيت الاعتماديات
npm install

# تشغيل خادم التطوير
npm run dev

# بناء النسخة الإنتاجية
npm run build
```

## 🐳 النشر عبر Docker & Coolify

تم إعداد المشروع ليدعم النشر التلقائي بنقرة واحدة عبر **Coolify**:

1. قم بربط مستودع GitHub الخاص بك في Coolify.
2. اختر نوع التطبيق: **Docker Compose** أو **Dockerfile / Static**.
3. حدد المنفذ (Port): `80` (أو `3000`).
4. سيتولى Coolify البناء وتشغيل الحاوية عبر Nginx تلقائياً مع شهادة SSL مجانية.
